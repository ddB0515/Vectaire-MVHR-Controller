# Left side

TOP
* Serial that will be connected to ESP32 display board (or headless board)
  
Bottom
* IN from MVHR that goues to XH 2.54 3pin connector (so each opening/disconnecting is easier)
* Jumper(Red) is if someone want to have external switch) needs to be bridged if want contact power/ON
  
RIGHT
* USB connector that convert 12V from MVHR to 5V for USB to power ESP32 boards/display

If anyone want to buy adapter or PCB have around 5 spare boards(assembled) and 10 clean PCB
